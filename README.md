# O Milhão do Processo

Quiz show de revisão de **Processo de Software**: 80 perguntas, modos de 16, 24 e 32 perguntas valendo 1 milhão (de mentirinha), apresentador com voz, música e explicação de todas as alternativas.

▶️ **Jogar:** https://estudoparaminhaprova.github.io/

Funciona no PC e no celular. Para a voz mais natural, use o Microsoft Edge.
